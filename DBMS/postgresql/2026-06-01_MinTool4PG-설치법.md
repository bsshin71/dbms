## 1. 핵심 요약
- WSL2/PowerShell이 제한된 Windows Terminal 환경에서 PostgreSQL DBA 작업을 수행하기 위한 Windows 전용 스크립트 도구 모음.

## 2. 상세 설명

### 개요
- 원래 이름: DbToys4Pg → 변경 예정 이름: **MinTool4PG**
- **대상 환경**: 프로젝트 환경에서 WSL2나 PowerShell이 막혀 있고 Windows Terminal만 사용 가능한 DBA
- 기존 Linux 터미널 스크립트를 대체하는 Windows 전용 도구

### 주요 기능

| 기능 | 설명 |
|------|------|
| 테이블 정보 | 인덱스, 통계정보 (DB 엔진 기본 기능 활용 → 빠른 응답 + 누락 속성 방지) |
| PLAN 가독성 | 읽기 쉬운 실행계획 출력 |
| 세션 모니터링 | Active Session / Lock Wait 모니터링 |
| DB 속성 비교 | DB properties 비교 |
| DDL 추출 | Oracle `DBMS_METADATA.GET_DDL`과 유사한 기능 |

### 설치 방법

#### 1단계 — 사전 소프트웨어 설치
1. **Windows용 Git 설치** — MinGW가 함께 설치되어 `cat`, `grep`, `sed`, `find`, `awk` 등 Linux 명령어 사용 가능
2. **Windows용 PostgreSQL CLI(psql) 설치** — 기본 경로: `C:\Program Files\PostgreSQL\17\bin`
3. **MinTool4PG 배포 파일 압축 해제** — `%USERPROFILE%\Desktop\DBA` 경로에 압축 해제

#### 2단계 — 환경 변수 설정

| 변수 | 값 |
|------|----|
| `DBAHOME` | `%USERPROFILE%\Desktop\DBA` |
| `MINGW` | `C:\Program Files\Git\usr\bin` |

PATH에 아래 경로 추가:
- `C:\Program Files\PostgreSQL\17\bin`
- `%MINGW%`
- `%DBAHOME%\bin`

#### 3단계 — pgpass.conf 설정 (패스워드 파일)

- 시스템 환경 변수 `PGPASSFILE`에 경로 지정
- 권장 경로: `%DBAHOME%\bin\config\pgpass.conf`
- 파일 내용 형식: `호스트:포트:DB명:사용자:비밀번호`

```
127.0.0.1:5432:*:postgres:passwd
192.168.1.50:5432:test_db:dev_user:dev_pass
```

> **Tip**: 파일 탐색기 주소창에 `%APPDATA%` 입력 → `postgresql` 폴더 생성(없으면) → 그 안에 `pgpass.conf` 파일 생성
