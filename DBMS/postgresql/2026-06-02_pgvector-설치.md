## 1. 핵심 요약
- PostgreSQL에서 벡터 데이터 타입과 유사도 검색(IVFFlat·HNSW)을 지원하는 오픈소스 확장 pgvector를 소스 빌드로 설치하고, 벡터 테이블 생성·삽입·검색까지 확인하는 절차.

## 2. 상세 설명

### 설치 환경
- OS: RHEL 8 (RedHat 8)
- PostgreSQL: 18.x (`/usr/pgsql-18/`)

### 설치 절차

#### 1단계 — 소스 클론
```bash
git clone https://github.com/pgvector/pgvector.git
cd pgvector
```

#### 2단계 — 빌드 준비 (postgresql-devel 설치)
`make` 실행 시 `/usr/pgsql-18/lib/pgxs/src/makefiles/pgxs.mk` 오류가 발생하면 devel 패키지가 없는 것이다.
```bash
# root 권한
dnf install postgresql18-devel
```
> Subscription Manager 경고가 떠도 패키지가 설치되면 무시해도 된다.

#### 3단계 — 빌드 및 설치
```bash
# postgres 계정
make

# root 계정
make install
```
빌드 후 `ls`에 `vector.so`가 생성되면 성공.

#### 4단계 — 확장 활성화
```sql
CREATE EXTENSION vector;

\dx  -- 설치 확인 (vector 0.8.2 항목 확인)
```

### 기본 사용 예시

```sql
-- 벡터 테이블 생성
CREATE TABLE items (
    id bigserial PRIMARY KEY,
    name varchar(50),
    embedding vector(3)
);

-- 데이터 삽입
INSERT INTO items (name, embedding) VALUES
('사과',   '[1.1, 2.2, 3.3]'),
('바나나', '[4.4, 5.5, 6.6]'),
('오렌지', '[1.0, 2.0, 3.0]');

-- 유사도 검색 (L2 거리 기준 가장 가까운 3개)
SELECT id, name, embedding
FROM items
ORDER BY embedding <-> '[1.2, 2.4, 3.1]'
LIMIT 3;
```

`<->` 연산자는 L2(유클리드) 거리를 사용한다. 결과는 `[1.1,2.2,3.3]`(사과) → `[1,2,3]`(오렌지) → `[4.4,5.5,6.6]`(바나나) 순으로 반환된다.

### 주요 연산자

| 연산자 | 의미 |
|--------|------|
| `<->` | L2(유클리드) 거리 |
| `<#>` | 내적(음수 내적) |
| `<=>` | 코사인 거리 |
