## 1. 핵심 요약
- PL/pgSQL DO 블록과 FOR 루프를 이용해 1년 범위 랜덤 날짜·카테고리·수량·가격으로 1000만 건의 판매 데이터를 자동 삽입하는 테스트 데이터 생성 스크립트

## 2. 상세 설명

### 스크립트 구조

```sql
DO $$
DECLARE
    i              INT;
    generated_date DATE;
BEGIN
    FOR i IN 1..10000000 LOOP
        -- 2023-01-01 ~ 2023-12-31 사이 랜덤 날짜 생성
        generated_date := DATE '2023-01-01' + (RANDOM() * 364)::INT;

        INSERT INTO new_sales (order_date, product_category, customer_id, quantity, price)
        VALUES (
            generated_date,
            CASE (i % 3)
                WHEN 0 THEN 'Electronics'
                WHEN 1 THEN 'Clothing'
                ELSE 'Home Appliances'
            END,
            (RANDOM() * 1000)::INT,        -- 고객 ID: 0~1000
            (RANDOM() * 10 + 1)::INT,      -- 수량: 1~10
            ROUND(RANDOM() * 100)::NUMERIC -- 가격: 0~100
        );
    END LOOP;
END $$;
```

### 핵심 기법

| 항목 | 방법 | 범위 |
|------|------|------|
| 날짜 | `DATE '2023-01-01' + (RANDOM() * 364)::INT` | 2023-01-01 ~ 2023-12-31 |
| 카테고리 | `CASE (i % 3)` — 3가지 균등 분배 | Electronics / Clothing / Home Appliances |
| 고객 ID | `(RANDOM() * 1000)::INT` | 0 ~ 1000 |
| 수량 | `(RANDOM() * 10 + 1)::INT` | 1 ~ 10 |
| 가격 | `ROUND(RANDOM() * 100)::NUMERIC` | 0 ~ 100 |

### 주의 사항
- `DO $$` 블록은 트랜잭션 단위로 실행되므로 1000만 건이 한 트랜잭션 내에서 커밋됩니다.  
  대용량 삽입 시 `COMMIT` 주기를 나누거나 `pg_sleep()` 인터벌을 추가하면 WAL 부하를 분산할 수 있습니다.
- `RANDOM()`은 PostgreSQL 의사난수(pseudo-random) 함수로 시드를 고정하려면 `SELECT setseed(0.5);`를 먼저 실행합니다.
- 날짜 범위 계산: `364`를 곱해 최대 365번째 날(12-31)까지 포함 (2023년은 윤년 아님).
