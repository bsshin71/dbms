# Oracle 유저 생성

- **작성일**: 2026-06-02
- **참조 원본**: `raw/clippings/2026-06-02-oracle 유저 생성하기 - MyWiki.md`

## 1. 핵심 요약
- Oracle 19c에서 사용자를 생성하려면 sysdba 접속 → `_ORACLE_SCRIPT` 세션 설정 → `CREATE USER` → `GRANT CONNECT, RESOURCE` 의 4단계를 순서대로 실행해야 한다.

## 2. 상세 설명

### 1단계 — 관리자 계정 접속
CMD/터미널에서 sysdba 권한으로 접속한다.
```sql
sqlplus "/as sysdba"
```

### 2단계 — 일반 세션 스크립트 활성화 (필수)
Oracle 12c 이후 멀티테넌트 아키텍처로 인해 기본적으로 사용자명 앞에 `C##` 접두사가 강제된다. 기존 방식(`C##` 없음)으로 생성하려면 반드시 먼저 실행해야 한다. 누락 시 **ORA-65096** 에러 발생.
```sql
ALTER SESSION SET "_ORACLE_SCRIPT" = TRUE;
```

### 3단계 — 사용자 계정 생성
비밀번호에 특수문자가 포함되면 쌍따옴표(`""`)로 감싼다.
```sql
CREATE USER 사용자명 IDENTIFIED BY 비밀번호;
```

### 4단계 — 접속 및 자원 사용 권한 부여
계정 생성 직후에는 권한이 없어 접속도 불가하므로 반드시 실행한다.
```sql
GRANT CONNECT, RESOURCE TO 사용자명;
```

### 추가 설정 (선택)
```sql
-- 테이블스페이스 할당량 무제한
ALTER USER 사용자명 DEFAULT TABLESPACE USERS QUOTA UNLIMITED ON USERS;

-- DBA 권한 부여 (테스트 환경 전용)
GRANT DBA TO 사용자명;
```
